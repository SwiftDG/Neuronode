# Neuronode

Neuronode is an interactive data-structures and algorithms tutor designed to make common coding patterns easier to understand and practise.

## Current experience

- Plain-language lessons for supported problems
- Guided practice and coding exercises
- JavaScript, Python and Java editor support
- Tests and progress views
- Account-based protected learning routes

The current learning set focuses primarily on array and hashing problems.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Stack

React, Vite, CodeMirror, Firebase, Framer Motion and Tailwind CSS.

## Project status

Neuronode is under active development. The available lessons and automated feedback cover only the problems currently implemented in the repository.
